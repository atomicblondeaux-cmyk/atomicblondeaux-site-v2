# Atomic Blondeaux — Site V2

Single-page static website for Atomic Blondeaux, LLC.

## Deployment
Designed for direct deployment on Netlify. No build command or framework is required.

- Publish directory: repository root
- Entry point: `index.html`

## Structure
- `index.html` — content and semantic page structure
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and copyright year

## Positioning
Atomic Blondeaux is presented as an interdisciplinary advisory practice spanning:
1. Historic Preservation & Section 106
2. Infrastructure & Digital Transformation
3. Policy, Research & Strategic Advisory

Digital-twin implementation is explicitly distinguished from Atomic Blondeaux advisory work and may be delivered in partnership with Digi Twin Global, LLC.
